# 训练／验证数据与接口分析

分析日期：2026-10-24。命令：`.venv\Scripts\python.exe code\analyze_data.py`。机器可读证据：`records/analysis/data-summary.json`。本分析只读取训练／验证参考，没有读取测试参考或评估测试成绩。

每个训练标签由候选文本和同题参考经 `common.parse_answer` 解析后比较得出；`None` 不能作为正确答案。需同时核对 ID 和题目，多个正确候选都为正例。不能把四选一任务误写成只有一个正确类别的训练问题。

解析器只接受最后一个 `####` 后的数值，或在没有 `####` 时接受最后一个简单 `\\boxed{...}` 中的数值。日常阅读看起来有答案的文本，可能因未满足格式而被官方判错；不能更改解析器，报告应区分这种失败与数学推理错误。

## 基础统计与研究意义

按最早候选打破平局的多数投票，在训练集正确 4,054/4,755（85.26%）；在验证集正确 688/798（86.22%）。仅看答案分歧题，分别为 1,413/2,114（66.84%）和 245/355（69.01%）。验证基线已通过官方评分器核对，完整记录见 [实验结果](EXPERIMENTS.md)。

四个候选均正确的题占训练集约 47.15%、验证集约 47.49%。而且只剩一种有效答案时，选择任意可解析候选就能正确。因此完整验证集含大量容易题。官方指南明确测试集只保留至少两种有效答案的题，研究必须同时报告完整验证与分歧子集成绩，不能仅由 86.22% 推断测试表现。

错误候选平均更长，但长度本身不能证明错误。最短候选基线和表面特征模型用于检验这些线索的预测作用，统计相关不作为因果结论。

## 固定表示

训练／验证接口形状分别为 `[4755,4,1024]` 和 `[798,4,1024]`，均为 float32。向量范数平均约为 57.64 和 57.59，表示未经单位范数归一化。训练变换只能在训练集拟合，不能把验证或测试数据混入均值、方差估计。

## 方法接口与实验设计

方法实现于 `selection.predict(bank, arrays, checkpoint)`，通过官方 `predict.py --method selection.py` 调用，官方 `submission.py` 保持空接口原样。输出与题库顺序对齐，每题返回一个原生整数 0–3。推理模块不导入训练数据加载函数、不读取参考，不按题目 ID 查表。

固定实验协议见 [RESEARCH_PROTOCOL.md](RESEARCH_PROTOCOL.md)。实验比较多数投票等基线、固定表示、表面特征、成对训练和答案聚合，并分别报告完整验证集与答案分歧子集表现。

# 验证实验协议 v1（2026-10-24，正式搜索前确定）

## 主问题与假设

在四个候选答案存在分歧时，固定全解答表示中的线性信号，能否超过多数投票？加入候选间答案一致性、对相同答案的得分进行平均，是否改善选择？长度和格式等表面特征能否解释收益？

假设：同题的正确／错误候选成对学习能消除题目间的共同因素；候选共识提供与表示互补的证据。风险是表面特征和易题使总体准确率过于乐观，因此必须分别报告完整验证集及其答案分歧子集。

## 数据边界和选择规则

- 仅使用官方训练集拟合，包括标准化均值和方差。多个正确候选全部标为正例；解析严格使用官方 `common.parse_answer`。
- 验证集用于开发。分歧子集定义为四候选存在至少两个不同、可被官方解析器解析的答案；只根据候选文本构造，不根据正确标签筛选。
- 最终选择顺序：分歧子集正确题数最多；其次完整验证集正确题数最多；其次资产更小；最后按实验 ID 排序。该规则在运行搜索前确定。
- 验证研究期间不访问测试参考答案，不运行测试评分；最终测试在方法冻结后单独执行。官方指南已公开测试集采用分歧条件，本研究仅据此设定验证指标。
- 分歧子集用于模型选择，不是独立测试集；报告其选择偏差，不把验证提升称为已确认的泛化提升。

## 固定实验矩阵

免训练基线三项：固定第一个候选、多数投票、最短可解析候选。相同票数／分数一律选择最早的候选；解析失败候选在除固定第一项之外的方法中屏蔽。

| 模型族 | 输入 | 训练目标 | 用途 |
|---|---|---|---|
| surface / pairwise | 12 个长度、格式和最终数值特征 | 同题正负候选差值回归 | 表面线索消融 |
| embedding / pointwise | 1024 维固定表示 | 独立候选 0/1 岭回归 | 独立判断对照 |
| embedding / pairwise | 1024 维固定表示 | 同题正负候选差值回归 | 候选比较消融 |
| embedding_surface / pairwise | 表示 + 12 个表面特征 | 同上 | 去掉投票特征消融 |
| full / pairwise | 表示 + 表面特征 + 3 个答案共识特征 | 同上 | 完整方法 |

每族的正则参数 alpha 固定为 0.1、1、10；共 15 次拟合。每个拟合结果比较直接候选得分及同答案候选平均得分两种方式，共 30 个学习配置，加 3 个基线，共 33 个验证配置。不根据测试成绩扩展搜索。

所有方法为确定性闭式线性模型，记录种子 20261024（拟合不使用随机数）。训练只比较可解析的候选；成对目标按每题权重均衡，四个答案均正确的题目不提供正负对。标准化仅使用训练集可解析候选，常量维度缩放设为 1。

表面特征：log(1+字符数)、词数、换行数、数字串数、等号数、反斜杠数、加粗标记数；#### 标记、boxed 标记、能否解析；带符号的 log(1+答案绝对值，截断在 10^12)；答案是否整数。前三个共识特征为答案出现频率、是否处于最高票组、是否独占答案。输入可从新题库直接计算，不依赖 ID 或缓存。

## 执行与记录

从根目录执行：`.venv\Scripts\python.exe code\analyze_data.py`，再执行 `.venv\Scripts\python.exe code\run_experiments.py`。脚本拒绝覆盖已有搜索目录。

每个配置在新进程中运行官方预测和独立评分，保存官方 JSON、完整命令、外部总耗时、拟合／特征提取耗时和资产哈希。所有库线程上限设为 4；顺序执行，无进程并行。最后记录整个搜索墙钟时间及源文件哈希。

分析比较配对的正确→错误与错误→正确计数，报告净提升和失败案例，并在可比较配置中隔离特征／目标／聚合变化，保留负结果。资源预检、未知题库适配及冻结证据分别记录于 `records/robustness/` 和 `records/final/freeze.json`。
